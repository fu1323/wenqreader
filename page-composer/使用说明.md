# 分片合成工具

双击 `分片合成工具.html`，用 Safari、Chrome 或 Edge 打开。无需安装依赖，不联网、不上传文件。

1. 点击“选择文件夹”，选择 Java 客户端某一页的输出目录。也可以多选或分次拖入 `manifest.json` 与全部 `fragment-*` 图片。
2. 点击“合成整页”，检查预览。
3. 点击“下载 PNG”。文件名为 `book-书号-page-页码.png`，保存位置由浏览器决定。

工具按 manifest 的 fragmentId 定位图片，不按选择或下载顺序排列。使用 geometry 的普通片宽、末片宽、高度及角度，整体旋转后输出原始尺寸。支持 0、90、180、270 度及其等价角度，不自动缩放，不混入 preview。

只有预览图、或第 100 页返回 40109 后未取得高清分片的目录，无法合成。缺片、重复编号或尺寸不匹配会明确提示并停止。一次请选择一个页面目录。

适配已分析的阅读器 8.0.422 布局。限制画布单边 32767 像素、总计 4000 万像素。原始文件保持不变。本工具仅做本地拼合，不访问阅读网站。

## 验证记录

已在本地 Chromium 中验证抓包中第 1、2、9、10、11、12、13 页的 42 张真实分片合成及 PNG 下载。四种旋转角度与独立生成的期望图片逐像素一致；缺失文件、重复编号、几何参数异常等检查通过，目录选择和手机宽度布局检查通过，未发出网络请求。Safari/Edge 未逐一执行自动化测试。
